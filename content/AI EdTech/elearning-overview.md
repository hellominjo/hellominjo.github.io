## 1. 이러닝의 정의

이러닝의 **'e'** 는 단순히 전자적(Electronic) 수단만을 뜻하지 않습니다. 언제 어디서나 학습이 가능한 환경(**Everywhere, Anytime**)이라는 의미를 함께 담고 있습니다.

### 전통적 교육과의 비교

| | 전통적 교육 | 이러닝 |
|---|---|---|
| 교육 장소 | 교실 | 인터넷이 되는 모든 곳 |
| 교육 시간 | 정해진 시간표 | 학습자가 원하는 시간 |
| 상호작용 | 직접적 소통 | 간접적·비동기적 소통 |
| 학습 속도 | 일관된 커리큘럼 | 자기 주도적 속도 조절 |
| 비용 | 교재비·교통비 발생 | 상대적으로 경제적 |
| 학습 효과 | 동기 부여와 교감에 강점 | 반복 학습은 쉬우나 **집중력 저하·이탈 가능성** |

### 블렌디드 러닝과 플립 러닝

두 방식의 장점을 결합한 것이 **블렌디드 러닝**이고, 그중 **플립 러닝(거꾸로 교실)** 은 온라인으로 먼저 개념을 학습하고 교실에서는 토론·실습에 집중하는 형태입니다.

## 2. 이러닝의 역사

| 시기 | 사건 |
|---|---|
| **1840년대** | 아이작 피트먼이 **우편**으로 과제를 보내고 피드백 — 최초의 원격 교육 |
| **1924년** | 오하이오 대학 시드니 필스 교수가 **'티칭 머신'** 개념 제시 |
| **1950년** | 앨런 튜링이 **튜링 테스트** 발표 |
| **1950년대** | 하버드 B.F. 스키너가 보상 체계를 결합한 티칭 머신 실제 개발 |
| **1960년** | 일리노이 대학교, 세계 최초의 컴퓨터 기반 교육 시스템 **PLATO** 개발 (약 40년간 운영) |
| **1966년** | MIT 조셉 바이젠바움의 최초 챗봇 **ELIZA** 등장 (패턴 매칭 방식) |
| **1970–80년대** | 상호작용이 추가된 **CBT**(Computer-Based Training), PC와 CD-ROM 보급 |
| **1990년대** | 인터넷 발전으로 **WBT**(Web-Based Training) 시작 |

흐름을 보면 **원격 전달 → 자동 피드백 → 상호작용 → 네트워크 연결**로 한 겹씩 쌓여온 것을 알 수 있습니다.

## 3. 플랫폼 중심의 대중화

| 시기 | 사건 |
|---|---|
| **1999년** | 교육 분야에 **LMS**(학습관리시스템) 도입 |
| **2001년** | 오픈소스 LMS **Moodle** 출시 |
| **2007–2008년** | 칸 아카데미 등 **MOOC** 등장 |
| **2012년** | Coursera, Udacity, edX 설립 |
| **2015년 이후** | 모바일·클라우드로 스마트폰 학습 활성화, **학습 데이터 분석** 부상 |

## 4. 이러닝 시스템의 구성 요소

| 요소 | 역할 |
|---|---|
| **LMS** (학습관리시스템) | 강좌·학습자·콘텐츠·학습 활동을 통합 관리. **학습 이력과 성취도** 파악에 중점 |
| **LCMS** (학습콘텐츠관리시스템) | **학습 객체(Learning Object)** 단위로 콘텐츠를 제작·저장·재사용 |
| **인프라 및 전송 기술** | 안정적 동영상 송출을 위한 스트리밍, 저작권 보호를 위한 **DRM** |
| **인적 구성 요소** | 학습자 · 교수자 · 운영자 |

> LMS, LCMS, MOOC는 실제로는 서로의 기능을 포함하며 다양한 형태로 결합되어 운영됩니다. 개념 구분은 설명을 위한 것이지 제품 경계가 아닙니다.

## 5. 한국의 이러닝 발전사

| 시기 | 내용 |
|---|---|
| **1990년대** | PC 통신을 통한 학습 시작 |
| **2000년대** | 메가스터디·EBS 수능 강의의 성공으로 공교육·사교육의 핵심 매체로 자리잡음. **2004년 이러닝 산업발전법** 제정 |
| **2010년대** | 스마트폰 보급과 함께 **'스마트 러닝'** 으로 진화, **K-MOOC** 출범 |
| **2020년대** | 코로나19로 비대면 시대 도래, Zoom 등 에듀테크 급성장 |

## 6. AI 기반 이러닝의 현재와 미래

**현재** — 초개인화·적응형 학습으로 실시간 피드백과 개별 학습 경로 제시가 가능해졌습니다. 경기도교육청의 '하이디'처럼 공교육 현장에도 적용되고 있습니다.

**미래** — 학습 목표를 이해하고 학습 경로를 스스로 설계하는 **AI 에이전트** 기반 지능형 튜터가 등장할 것으로 전망됩니다. 메타버스와 VR/AR을 활용한 몰입형 학습 환경도 확장될 것으로 보입니다.
