## 공공데이터포털 가입과 API 인증키 발급

공공데이터포털은 정부·공공기관 데이터를 무료로 제공합니다. 가입과 사용 모두 비용이 들지 않고, **인증키는 계정당 하나**가 발급돼 모든 데이터셋을 이 키 하나로 호출합니다.

**1)공공데이터 포털 가입 ([공공데이터포털](https://www.data.go.kr/))**

![[1. 데이터 분석 프로젝트-20260913130718507.png]]

![[1. 데이터 분석 프로젝트-20260913130847953.png]]

![[1. 데이터 분석 프로젝트-20260913131137709.png]]

- 회원가입 완료
![[1. 데이터 분석 프로젝트-20260913131203442.png]]

- 원하는 자료 검색 (ex. 아파트매매실거래가 자료 ) > [활용신청]
![[1. 데이터 분석 프로젝트-20260913131427557.png]]

- 'OpenAPI 개발계정 신청' > 웹사이트 개발 선택 > 동의합니다.
![[1. 데이터 분석 프로젝트-20260913131608998.png]]

![[1. 데이터 분석 프로젝트-20260913131638384.png]]

- 활용 신청 및 승인 현황 
![[1. 데이터 분석 프로젝트-20260913131752542.png]]

!Tip. 개인이 아닌 개입이라면 따로 심사를 거쳐 대규모 트래픽 가능한 계정 할당 가능
라이선스 표시의 경우 저작자 표시 필요


**2)API 인증키 확인**

- 마이페이지 > API 인증키 확인
![[1. 데이터 분석 프로젝트-20260913132034917.png]]

-기술 문서 다운로드 및 인증키 확인
![[1. 데이터 분석 프로젝트-20260913132417271.png]]

## 알아두면 좋은 점

| 항목 | 내용 |
|---|---|
| 승인 시간 | 자동 승인은 즉시, 기관 심사는 평일 기준 10분 ~ 3일 |
| 상세기능 체크 | 체크하지 않은 오퍼레이션은 인증 오류가 납니다. 쓸 것 같은 항목은 미리 전부 체크 |
| 인증키 종류 | Encoding / Decoding 두 가지가 발급됩니다 — 구분은 다음 글에서 다룹니다 |
| 트래픽 한도 | 개발계정은 보통 일 1,000건 수준 |

신청 직후 호출했는데 인증 오류가 난다면 키가 틀린 게 아니라 **아직 전파되지 않았을 가능성**이 큽니다. 한 시간쯤 뒤에 다시 시도해보세요.
