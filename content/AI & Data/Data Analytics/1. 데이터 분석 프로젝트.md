##### 1) 데이터 분석 프로젝트 5단계

```mermaid
flowchart LR
    A[1단계<br/>문제정의] --> B[2단계<br/>데이터 수집] --> C[3단계<br/>전처리] --> D[4단계<br/>분석과 시각화] --> E[5단계<br/>서비스 구현과 운용]
```

- **1단계.문제 정의** : 분석의 대상 및 목적을 정하는 단계 ex. 아파트 가격 변화
- **2단계.데이터 수집** : 문제 정의에 필요한 요건 이해 및 실제 데이터 확보 (공공데이터 포털, 크롤러 등)
- **3단계.전처리** : 수집된 데이터를 바로 사용할 수 있는 경우는 거의 X 
   * 데이터 내 결측값(누락된 값)이나 이상값(벗어난 값) 등 오류 처리과정 필요
- **4단계.분석과 시각화** : 1단계에서 정의한 문제의 답을 찾는 단계
  * 한꺼번에 많은 숫자나 데이터를 인지하기 어려움
  * 그래프나 차트를 이용하여 데이터의 흐름과 변화를 파악하고 이해하기 쉽게 이미지로 표현
- **5단계.서비스 구현과 운용** : 분석 결과를 다른 사용자와 함께 공유 하는 것
  - 데이터 기반 의사결정 도구로 활용할 수 있는 웹 애플리케이션 제작

##### 자료 수집 방법 이해

```text
- 어떤 자료를 어떻게 수집할지는 분석에 소요되는 시간과 비용, 결과물의 수준을 결정
- API : 정보를 주문하는 클라이언트와 결과를 제공하는 서버 사이에서 요청과 응답 내용을 전달해 주는 매개체
  * API는 이용할 수 있는 권한으로서 허용된 사용자에게 데이터를 제공하므로 이용하려면 **인증키가 필요**
```
