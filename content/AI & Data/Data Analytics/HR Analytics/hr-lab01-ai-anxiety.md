> **연구 질문**: 두 연령집단 간 AI 불안 요인에 통계적으로 유의한 차이가 있는가?

조직에 AI를 도입할 때 "나이 많은 직원이 더 불안해한다"는 전제가 흔히 깔립니다. 이 실습은 그 전제가 **어떤 종류의 불안에서 성립하는지**를 데이터로 확인합니다.

## 1. 데이터와 변수

- **데이터**: `Sample_data_AI Anxiety.xlsx` (HR 애널리틱스 과정 설문 자료)
- **집단 구분**: 50세 미만 / 50세 이상

측정한 불안 요인은 세 가지이고, 각각 3문항 척도로 측정했습니다.

| 요인 | 내용 |
|---|---|
| 학습 불안 | 새로운 기술을 익혀야 한다는 부담 |
| 일자리 대체 불안 | AI가 내 업무를 대신할 것이라는 우려 |
| 프라이버시 침해 불안 | 개인 정보가 수집·활용되는 것에 대한 우려 |

## 2. 분석 방법

1. 연령집단별 기술통계 (N, 평균, 표준편차)
2. **Welch's t-test** — 독립표본 평균 차이 검정
3. **Cohen's d** — 효과크기 계산
4. 유의수준 **α = .05**

> 등분산을 가정하는 Student's t-test 대신 **Welch's t-test**를 쓴 이유는, 두 집단의 표본 크기와 분산이 다를 수 있기 때문입니다. 등분산 가정이 깨졌을 때도 비교적 안전합니다.

## 3. 분석 코드

```r
library(readxl)
library(dplyr)
library(effsize)

df <- read_excel("Sample_data_AI Anxiety.xlsx")

# 연령집단 구분
df <- df %>%
  mutate(age_group = ifelse(age >= 50, "50세 이상", "50세 미만"))

# 기술통계
df %>%
  group_by(age_group) %>%
  summarise(n = n(),
            mean = mean(privacy, na.rm = TRUE),
            sd   = sd(privacy,   na.rm = TRUE))

# Welch's t-test (var.equal = FALSE가 기본값)
t.test(privacy ~ age_group, data = df, var.equal = FALSE)

# 효과크기
cohen.d(privacy ~ age_group, data = df)
```

세 요인 각각에 대해 같은 절차를 반복합니다.

## 4. 결과

| 불안 요인 | 평균 차이 | p | Cohen's d | 판정 |
|---|---|---|---|---|
| 학습 불안 | -0.182 | .2334 | -0.136 | 유의하지 않음 |
| 일자리 대체 불안 | -0.136 | .3564 | -0.106 | 유의하지 않음 |
| **프라이버시 침해 불안** | **-0.299** | **.0317** | **-0.242** | **유의 (작은 효과)** |

프라이버시 침해 불안에서만 유의한 차이가 나왔고, **50세 이상 집단(M = 5.220)이 50세 미만 집단(M = 4.921)보다 높았습니다.**

## 5. 해석

**연령이 AI 불안 전반을 설명하지는 못합니다.** 세 요인 중 둘은 집단 차이가 없었고, 차이가 난 하나도 Cohen's d가 -0.242로 **작은 효과**에 해당합니다.

- `p = .0317`은 "차이가 우연일 가능성이 낮다"는 뜻이지, "차이가 크다"는 뜻이 아닙니다.
- 효과크기까지 함께 봐야 실무적으로 의미 있는 차이인지 판단할 수 있습니다.

**실무 함의**: AI 도입 시 연령대별로 다른 교육 프로그램을 설계하는 것보다, **전 연령을 대상으로 데이터 보호 정책을 명확히 고지하는 편**이 근거에 더 부합합니다. 학습 불안과 일자리 불안은 연령과 무관하게 나타났으므로, 연령으로 대상을 나누는 접근 자체가 적절하지 않습니다.
