> **연구 질문**: 인사 특성으로 고성과자일 확률을 예측할 수 있는가? 어떤 변수가 성과와 관련되는가?

종속변수가 "고성과자다 / 아니다"처럼 **두 값 중 하나**일 때는 선형 회귀를 쓸 수 없습니다. 확률이 0~1 범위를 벗어나기 때문입니다. 이 실습은 **이항 로지스틱 회귀**로 접근합니다.

## 1. 데이터와 변수

- **모델 구축**: `ch3_performance.xlsx`
- **검증**: `test.xlsx` (신규 입사자 5명)
- **종속변수**: 성과 (1 = 고성과자, 0 = 저성과자)

독립변수는 11개입니다.

| 유형 | 변수 |
|---|---|
| 범주형 | 결혼 여부, 성별, 학력 |
| 수치형 | 근무시간, 근태 사고율, 연령, 리더십 역량, 급여, 근속연수, 조직 적합도, 직무 만족도 |

**데이터 준비**: 범주형 변수는 기준 범주(reference category)를 지정해 더미 코딩하고, 수치형은 원래 값을 유지했습니다.

## 2. 분석 절차

1. `glm(family = binomial)`로 이항 로지스틱 회귀 적합
2. 회귀계수를 지수 변환해 **오즈비(OR)**와 95% 신뢰구간 산출
3. **GVIF**로 다중공선성 진단
4. 우도비 카이제곱 검정과 **AIC**로 모형 적합도 평가
5. 확률 기준값 **0.5**로 혼동행렬 작성
6. 신규 입사자 5명 예측값을 실제 결과와 비교

## 3. 분석 코드

```r
library(readxl)
library(dplyr)
library(car)      # GVIF

df <- read_excel("ch3_performance.xlsx")

# 범주형 변수에 기준 범주 지정
df <- df %>%
  mutate(across(c(marital, gender, education), as.factor))

# 이항 로지스틱 회귀
model <- glm(performance ~ ., data = df, family = binomial)
summary(model)

# 오즈비와 95% 신뢰구간
exp(cbind(OR = coef(model), confint(model)))

# 다중공선성 진단
vif(model)

# 분류 성능 (기준값 0.5)
pred <- ifelse(predict(model, type = "response") >= 0.5, 1, 0)
table(예측 = pred, 실제 = df$performance)
```

> **오즈비를 쓰는 이유**: 로지스틱 회귀의 계수는 로그 오즈 단위라 그대로 읽기 어렵습니다. `exp()`로 변환하면 "이 변수가 1 증가할 때 고성과자일 오즈가 몇 배가 되는가"로 해석할 수 있습니다. OR = 1이면 관련이 없다는 뜻입니다.

## 4. 분류 성능

| 지표 | 값 | 의미 |
|---|---|---|
| 정확도 (Accuracy) | 72.4% | 전체 중 맞게 분류한 비율 |
| **민감도 (Sensitivity)** | **54.7%** | 실제 고성과자를 고성과자로 맞춘 비율 |
| **특이도 (Specificity)** | **84.1%** | 실제 저성과자를 저성과자로 맞춘 비율 |

## 5. 해석 — 정확도만 보면 안 되는 이유

**특이도(84.1%)가 민감도(54.7%)보다 크게 높습니다.** 저성과자는 잘 걸러내지만, **고성과자는 절반 가까이 놓칩니다.**

정확도 72.4%만 보면 쓸 만해 보이지만, 실제로 이 모형은 **"저성과자 판별기"에 가깝습니다.** 고성과자를 찾아내는 용도로 쓰면 기대와 다르게 동작합니다.

신규 입사자 5명 중 4명을 맞혔고, 틀린 한 명(3번)은 **실제 고성과자인데 예측 확률이 0.343**이라 기준값 0.5에 못 미쳐 저성과자로 분류됐습니다. 민감도가 낮다는 점이 개별 사례에서 그대로 드러난 경우입니다.

## 6. 남는 한계

- **기준값은 고정값이 아닙니다.** 고성과자를 놓치지 않는 게 중요하다면 0.5를 낮춰 민감도를 올릴 수 있습니다. 대신 특이도가 떨어집니다. 조직의 목적에 따라 조정해야 할 값입니다.
- **검증 표본이 5명**입니다. 일반화하기에는 너무 작습니다.
- 이 결과는 인재 관리 의사결정의 **보조 자료**이지 판단의 근거가 될 수준은 아닙니다.
